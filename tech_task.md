## КОНТЕКСТ

Веб-сервис формирования юридических документов. Работает полностью на ПК
пользователя. Запуск через Docker, доступ по http://localhost:8080.
Open source, лицензия MIT. Данные пользователя не покидают его машину
(кроме транзитных запросов к публичным API для автозаполнения).

## СТЕК

- Backend: Python 3.12, FastAPI, httpx, uvicorn
- PDF: WeasyPrint (HTML→PDF) ИЛИ @react-pdf/renderer — выбери один,
  обоснуй в README. Кириллица обязательна (шрифт Roboto/PT Sans
  положи в репозиторий, не качай из интернета при старте).
- Frontend: Bootstrap 5, vanilla JS (без сборщиков, без Node.js,
  если выбран WeasyPrint)
- Контейнеризация: Docker, docker-compose
- Тесты: pytest, Playwright (e2e)

## АРХИТЕКТУРА (не менять)

- Один контейнер, один порт 8080:8080
- Без Nginx, без CORS (один origin)
- FastAPI отдаёт статику через StaticFiles
- Тонкий прокси на httpx внутри FastAPI для внешних API
- Логи — в stdout, доступны через docker logs
- Непривилегированный пользователь в контейнере (USER appuser)
- STOPSIGNAL SIGTERM
