# DocMaker — Пошаговый план реализации

## Ключевые решения

| Решение | Выбор | Обоснование |
|---|---|---|
| PDF-библиотека | **WeasyPrint** | Нативная поддержка кириллицы через TTF, HTML→PDF, интеграция с Jinja2, без Node.js |
| Шаблонизатор | **Jinja2** | Нативная интеграция с FastAPI, рендеринг HTML для превью и PDF |
| Шрифт | **PT Sans** (TTF в репозитории) | Бесплатная лицензия, отличная кириллица, ~156 КБ |
| CDN | **Локальные копии** | Без внешних зависимостей при старте |
| Состояние | **localStorage** | Без серверного хранения, без БД |
| Прокси | **httpx async** | Тонкий прокси для внешних API, таймаут 10 сек, graceful degradation |

## ЭТАП 1: Скелет проекта

**Цель:** Docker-контейнер запускается, раздаёт index.html на порту 8080, `/health` возвращает 200.

### Создаваемые файлы:

1. **`requirements.txt`** — зависимости: fastapi, uvicorn, httpx, jinja2, weasyprint, python-multipart
2. **`Dockerfile`** — python:3.12-slim, системные зависимости для WeasyPrint (Pango, Cairo, pixbuf), non-root user `appuser`, STOPSIGNAL SIGTERM, порт 8080
3. **`docker-compose.yml`** — сервис docmaker, порт 8080:8080, healthcheck на `/health`
4. **`app/__init__.py`** — пустой
5. **`app/main.py`** — FastAPI + StaticFiles + Jinja2Templates, маршруты `/health` и `/`
6. **`templates/index.html`** — базовый HTML с Bootstrap 5 (локальная копия)
7. **`static/css/main.css`** — базовые стили
8. **`static/js/main.js`** — инициализация, каталог 10 документов, навигация
9. **`static/js/document-wizard.js`** — класс DocumentWizard (форма → превью → PDF)
10. **`README.md`** — схема архитектуры, инструкция запуска, дисклеймер
11. **`LICENSE`** — MIT
12. **`CHANGELOG.md`** — начальная версия
13. **`.gitignore`**

### Верификация:
```bash
docker compose up --build
# Открыть http://localhost:8080 — должна отобразиться страница DocMaker
# Открыть http://localhost:8080/health — {"status":"ok","version":"0.1.0"}
```

### Структура полей для каждого документа:
- **completion.py**: issuer/recip info, work description, date, amount, signature
- **service_contract.py**: parties, subject, term, price, obligations, signatures
- **receipt.py**: issuer info, payment date, amount, service, QR placeholder
- **gift.py**: donor/donee info, property description, value, date, signatures
- **money_receipt.py**: recipient, amount (numbers + words), date, purpose, signatures
- **loan.py**: lender/borrower, amount, interest rate, term, repayment schedule
- **acceptance.py**: party info, work description, date, defects, signatures
- **pd_consent.py**: processing subject, purposes, data types, consent period, signatures
- **fns_application.py**: applicant info, relationship to donor, property details, FNS address

## ЭТАП 4: Открытые данные (автозаполнение)

**Цель:** Прокси для внешних API, цепочка fallback, локальные справочники, индикаторы источника.

### Создаваемые файлы:

1. **`app/proxy.py`** — thin proxy на httpx:
   - `fetch_by_inn(inn)` — List-Org → KontragentPro → Checko.ru → None
   - `fetch_by_bik(bik)` — локальный JSON-справочник ЦБ
   - `fetch_currency_rate(date, currency)` — ЦБ РФ
   - Таймаут 10 сек на запрос
   - Graceful degradation: при ошибке — None, форма работает с ручным вводом

2. **`app/data/banks.json`** — локальный справочник БИК/банк/корсчёт (ЦБ)
3. **`app/data/addresses.json`** — локальный справочник ФИАС/КЛАДР (выборка)
4. **`app/main.py`** — маршрут `/api/auto-fill/{type}/{value}` — вызов proxy

### UI-изменения:
- Индикатор источника: «заполнено из ЕГРЮЛ» / «введено вручную» (CSS-класс `.source-indicator`)
- При загрузке формы — автоматический fetch по ИНН/БИК (если заполнено)

### Верификация:
```bash
# С доступом в интернет: автозаполнение по ИНН
# Без доступа: форма работает с ручным вводом, без ошибок
```

## Шрифт PT Sans

Скачать PT Sans (бесплатно, https://www.fontsquirrel.com/fonts/pt-sans) и положить:
- `static/fonts/PTSans-Regular.ttf`
- `static/fonts/PTSans-Bold.ttf`

Подключить в CSS:
```css
@font-face {
    font-family: 'PT Sans';
    src: url('/static/fonts/PTSans-Regular.ttf') format('truetype');
    font-weight: normal;
}
@font-face {
    font-family: 'PT Sans';
    src: url('/static/fonts/PTSans-Bold.ttf') format('truetype');
    font-weight: bold;
}
```
