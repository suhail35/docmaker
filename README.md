# DocMaker — Генератор юридических документов в PDF

Генератор 10 юридических документов в PDF с автозаполнением по ИНН.

## Возможности

- **10 юридических документов** с кириллицей
- **Автозаполнение по ИНН** — данные подтягиваются из List-org.com
- **PDF генерация** через WeasyPrint
- **Все данные на ПК** — ничего не уходит на внешние серверы
- **Docker** — один контейнер, порт 8080

## Документы

### Самозанятые (НПД)
1. Счёт (НПД)
2. Акт выполненных работ
3. Договор возмездного оказания услуг
4. Чек-подтверждение

### Физические лица
5. Договор дарения движимого имущества
6. Расписка в получении денег
7. Договор займа между физлицами
8. Акт приёма-передачи
9. Согласие на обработку ПДн
10. Заявление-пояснение в ФНС

## Запуск

```bash
docker compose up -d --build
```

Открыть: http://localhost:8080

## Стек

- Python 3.12, FastAPI
- WeasyPrint (PDF)
- Bootstrap 5, vanilla JS
- Docker (Debian trixie)

## Тесты

```bash
docker compose exec docmaker pytest tests/ -v
```
