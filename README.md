# DocMaker

Веб-сервис для генерации юридических документов на Python/FastAPI.

## Архитектура

```
┌─────────────┐     ┌──────────────┐     ┌──────────┐
│   Browser    │────▶│  FastAPI     │────▶│ WeasyPrint│
│ (localhost   │     │  + Static    │     │ (PDF gen) │
│  :8080)      │◀────│  Files       │◀────│          │
└─────────────┘     └──────────────┘     └──────────┘
                         │
                         ▼
                   ┌──────────┐
                   │ External │
                   │  APIs    │
                   │ (optional)│
                   └──────────┘
```

**Ключевой принцип:** данные пользователя НЕ покидают его компьютер.
Все черновики хранятся в localStorage браузера.

## Запуск

```bash
docker compose up --build
```

Открыть http://localhost:8080

## Остановка

```bash
docker compose down
```

## Возможности

- 10 юридических документов для самозанятых и физлиц
- Генерация PDF с корректной кириллицей
- Предпросмотр перед скачиванием
- Автозаполнение по ИНН/БИК (при наличии интернета)
- Черновики в localStorage
- Работает полностью офлайн

## Проверка

1. **Запуск:** `docker compose up --build` → http://localhost:8080
2. **Документы:** каждый документ проходит цепочку форма → превью → PDF
3. **Оффлайн:** без интернета работает ручной ввод
4. **Автозаполнение:** при вводе ИНН — автозаполнение из внешних API
5. **Черновики:** данные сохраняются в браузере, кнопка «Очистить»
